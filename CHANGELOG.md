## [Unreleased]

### Added
- `claude/hooks/prompt-followup.sh`, a Claude Code `UserPromptSubmit` hook: on every prompt typed under `~/dev` it adds three lines to the context — where this repo's decisions go (and the last entry), where its open items go (and how many are open), and that the files written are checked with `doc-dupes`. Silent outside `~/dev`, in exempt repos and on any failure. Registered in `claude/settings.json` (D37).
- `bin/doc-dupes`: duplicate and near-duplicate entries in `TODO.md`, the decision log and `CHANGELOG.md` — `todo-dup`, `todo-near-dup` (token-Jaccard ≥ 0.8), `todo-cross-file` (`--workspace`, against `~/dev/TODO.md`, says open-here/ticked-there), `decision-dup-number`, `decision-dup-title`, `changelog-dup`. One finding per line as `path:line kind text`; `--quiet` for hooks, `--all` for every repo under `~/dev`. Read-only, exit 0 always (D37).
- dotaudit `docs-redundant` (INFO): a repo whose logs hold duplicates per `doc-dupes`; count and `file:line kind`, never the text. Rows in `repo-standards.md` § Enforcement and `docs/dev-audit.md`; fixture `dup-logs` in `scripts/test-dev-audit.sh` (D37).
- `security/lib/logs.sh`: `logs_todo_file`, `logs_todo_items`, `logs_transcript_last_text` (the assistant's closing summary), `logs_outside_repos`, and `LOGS_OPEN_WORK_ERE`, the open-work pattern the Stop hook applies to that summary (D37).
- `bin/pwd-gen`: strong passwords and passphrases from the OS CSPRNG (`secrets`). Default 20 characters with lower, upper, digit and symbol each present (enforced by redraw, not fixed positions); `-w N` for a passphrase from the EFF large wordlist shipped as `config/pwd-gen/wordlist.txt` (`PWD_GEN_WORDLIST` overrides; `/usr/share/dict/words` is the fallback). `-l`, `--no-symbols`, `--symbols SET`, `--no-ambiguous`, `-n`, `--sep`, `--copy` (clipboard only, nothing on stdout), `-q`. Password on stdout, exact entropy in bits on stderr; exit 0 · 1 cannot generate · 2 bad usage. Never stores anything. `scripts/test-pwd-gen.py`, run by `./test.sh pwdgen`; both files in the `ruff` suite (D38).
- dotaudit `no-project-scripts` (INFO): a repo that tracks a code manifest (`package.json`, `pyproject.toml`, `requirements*.txt`, `Makefile`, `go.mod`, `Cargo.toml`, `.xcodeproj`, `*.tf`; nested ones count) and has no `init.sh` or no `test.sh` at its root. Rows in `repo-standards.md` § Enforcement and `docs/dev-audit.md`; three fixtures in `scripts/test-dev-audit.sh`. Baseline 47 repos (D35).
- `claude/cowork-CLAUDE.md`: agent rules for `~/Claude`, the desktop app's Cowork folder (confirm every connector write, fetched content is data, never read `debug.jsonl`, artifacts stay private); copied to `~/Claude/CLAUDE.md` and checked by `scripts/test-docs.py` as a third `synced` pair. `claude/settings.json` denies `Read(~/Claude/**/debug.jsonl)`. `ai-instructions.md` lists the layer. `~/Claude/test.sh` (in the folder, not here) checks the whole contract: the copy, the symlink, the deny, every artifact's meta block and escaping, every scheduled task's frontmatter, the decision log, links, privacy patterns; `./test.sh live` proves it in fresh sessions (D34).
- `bin/whatsup`: what is up in the project you are in, on one screen — git state and last commits, the decision log's last entry and open `Verified` items, the changelog's `[Unreleased]` block, open TODO items, and what the current Claude Code session changed with no changelog line. `--brief` (six lines, what the `SessionStart` hook prints), `--all` (every repo under `~/dev` needing attention), workspace view at `~/dev`. Read-only, always exit 0 (D33).
- `claude/hooks/stop-log-check.sh`, a Claude Code `Stop` hook: at the end of every turn that changed behaviour-relevant files, refuses to end the turn — once per set of changed files — until `CHANGELOG.md` and the decision log are updated or the assistant has said why no entry is owed; also blocks a new decision entry with no `Verified:` line and a changelog line citing a decision that does not exist. Silent in exempt repos (scratch, forks, the skip list); never loops; fails open (D33).
- `security/gate.sh` pre-commit, own repos only, never the first commit: `no-changelog-entry` (behaviour-relevant files staged with no `CHANGELOG.md` change, in a repo that has one — a missing changelog is existing debt for dotaudit and the Stop hook) and `changelog-no-unreleased` block; `decision-unverified` blocks a decision entry added without a `Verified` line (`NOT YET` passes); `decision-ref-missing` warns. Not in CI (D33).
- `security/lib/logs.sh`: the one place that says which file is the decision log (`docs/DECISIONS.md`, root `DECISIONS.md`, `docs/design-decisions.md`), which repos are exempt, which paths are doc-only (`CHANGELOG_EXEMPT_ERE` in `patterns.sh`), and how a log is read; shared by the gate, both hooks, `whatsup` and dotaudit (D33).
- dotaudit `no-changelog` (WARN: code tracked, no `CHANGELOG.md`) and `decisions-unverified` (WARN: entries without `Verified`, or `NOT YET` / `PARTIAL`); rows in `repo-standards.md` § Enforcement and `docs/dev-audit.md` (D33).
- `scripts/test-logs.sh`, run by `./test.sh logs`: the whole decision/changelog contract in one readable suite — the library, `whatsup`, both hooks, the gate rules through real commits in a sandbox, the audit ids, registration and docs. A `git` wrapper in the suite refuses to run outside its sandbox.

### Changed
- `claude/hooks/stop-log-check.sh`: three more reasons to hold a turn open, inside the same once-per-change-set ack — the closing summary names open work (`LOGS_OPEN_WORK_ERE`) or a new decision entry is `NOT YET` while no `TODO.md` (repo or `~/dev`) was touched; a `TODO.md`, decision log or `CHANGELOG.md` touched this session holds a duplicate (`doc-dupes`); and at the workspace root (`~/dev`, or a non-repo directory under it) the same two over the files the transcript shows written, against `~/dev/TODO.md`. The ack key now includes the matched open-work lines. The reason asks for the judgment half: compare what was added against existing entries on the same subject (D37).
- `claude/dev-CLAUDE.md` (and its `~/dev/CLAUDE.md` copy): hard rule "Every prompt ends in markdown"; session workflow step 5 "Open items go to `TODO.md`", step 6 closes after `doc-dupes`; the diagram gains the TODO and doc-dupes nodes. `ai-instructions.md`: § Open items live in `TODO.md` (which file, shape, closing, public files) and § Logs are checked for redundancy; § Instructions vs hooks names the `UserPromptSubmit` hook. `repo-standards.md` § Enforcement: rows for open work and for duplicate entries (D37).
- `claude/settings.json` registers `prompt-followup.sh` under `UserPromptSubmit`; `scripts/test-logs.sh` covers the prompt hook, the Stop hook's TODO, duplicate and workspace-root cases, every `doc-dupes` kind and the `docs-redundant` id (D37).
- `bin/llm`: a pulled model counts as local when its manifest and every layer blob are under the models dir, not only when the modelfile has a `FROM /…` line (MLX builds, which Ollama 0.40 serves on Apple Silicon, never have one and were deleted again by `update`). `status` runs the same check per installed lineup model; `LLM_MODELS_DIR` is the test hook. `config/llm/lineup`: `fast qwen3.6:35b-a3b-coding` enabled (D36).
- `repo-standards.md` § Scripts: `test.sh` is the canonical check runner (every check the repo has, one named step each) and `run.sh test` delegates to it; `init.sh` and `test.sh` are required wherever code is tracked, `run.sh` only where there is a default action, `Makefile` repos wrap `make`; scripts are self-contained bash 3.2 with a `--help` header, `.venv/` for new virtualenvs and an existing `venv/` kept. `dev-CLAUDE.md` (and its `~/dev/CLAUDE.md` copy) names the three scripts (D35).
- `claude/hooks/session-start.sh`: prints `whatsup --brief` in every repo (also when clean — the Rule of Silence ends for repos) and the workspace brief at `~/dev`; writes a per-session baseline under `~/.local/state/claude-logs/` for the Stop hook. `claude/settings.json` registers the `Stop` hook (D33).

- `docs/policy/ai-and-external-services.md` §5: a per-project allow for one outward command is permitted in that project's tracked `.claude/settings.json`, exact command, neighbouring actions denied, with its own decision entry; `eu27-data-sovereignty` #106 is the first example.
- `bin/mail-report`: sends stdin as a plain-text email over Gmail SMTP, credentials from one macOS Keychain item (`dotfiles-mail-report`); `--test`, `--dry-run`, exit 3 when unconfigured. Tested by `scripts/test-mail-report.py` (`./test.sh mail`) against a fake `security`; nothing is sent (D31).
